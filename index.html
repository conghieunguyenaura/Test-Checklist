Đồng bộ Google Sheets & Google Drive

Chế độ Chạy Thử (Test Mode / Local)

Hiện tại bạn chưa dán URL Google Apps Script. Dữ liệu sẽ lưu tạm ở bộ nhớ trình duyệt. Bấm nút "Cấu hình Web App URL" để kết nối Sheets & Drive.

Mã Google Apps Script (3 bước đơn giản)

  1. Mở file Google Sheet của bạn > Chọn Tiện ích mở rộng (Extensions) > Apps Script.
  2. Xóa toàn bộ code cũ, dán đoạn code Google Apps Script ở phía dưới vào và thay FOLDER_ID bằng ID thư mục Google Drive của bạn.
  3. Nhấn Triển khai (Deploy) > Thực thi dưới dạng Web app > Chọn quyền truy cập: "Ai cũng có thể truy cập" (Anyone) > Copy URL Web App và dán vào phần cấu hình trang này.
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var folderId = "THAY_FOLDER_ID_DRIVE_CUO_BAN_VAO_DAY"; // ID Thư mục Drive
    var folder = DriveApp.getFolderById(folderId);

    // Xử lý lưu file hình ảnh
    var fileUrl = "";
    if (data.image) {
      var contentType = data.image.substring(5, data.image.indexOf(';'));
      var bytes = Utilities.base64Decode(data.image.substr(data.image.indexOf('base64,') + 7));
      var blob = Utilities.newBlob(bytes, contentType, data.imageName || "NghiemThu_" + Date.now() + ".jpg");
      var file = folder.createFile(blob);
      fileUrl = file.getUrl();
    }

    // Ghi dữ liệu vào Google Sheet
    sheet.appendRow([
      new Date(),
      data.projectName,
      data.itemCheck,
      data.inspector,
      data.status,
      data.notes,
      fileUrl
    ]);

    return ContentService.createTextOutput(JSON.stringify({result: "success", fileUrl: fileUrl}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", error: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Hướng Dẫn Test Nhanh

1. Form đã điền sẵn 1 dòng dữ liệu mẫu và hình ảnh minh họa giả lập.

2. Chọn một tấm ảnh thực tế từ máy/điện thoại của bạn.

3. Nhấn "Lưu & Gửi Nghiệm Thu". Dữ liệu sẽ xuất hiện lập tức ở ô bên trên.
